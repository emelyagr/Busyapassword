<h1>Busyapassword</h1>

<img src="https://github.com/emelyagr/Busyapassword/blob/main/LogoBusyapassword.png" class="center" width="450" height="450"> 
Busyapassword - программа менеджер паролей. Банковский уровень шифрования — бесплатно и полностью под вашим контролем.

<h2>Использование</h2>

1. Скачайте из релиза (Releases: https://github.com/emelyagr/Busyapassword/releases/tag/v1.0.0) файл "Busyapassword.exe".
2. Запустите скачанный файл.
3. Введите мастер-пароль (запомните и запишите его! потеряв этот пароль восстановить данные не получится).
4. Вводите свои логины и пароли от сервисов (наименования сервисов можно маскировать, например, не "Госуслуги", а "красно-синий").
5. Все пароли сохраняются в созданном автоматически файле (базе) формата "*.json" (удалив этот файл восстановить данные не получится).

<h2>Преимущества, недостатки и особенности</h2>

✅Если Вы не доверяете бинарному файлу формата "*.exe", можете скомпилировать файл формата "*.py" самостоятельно (предварительно изучив открытый исходный код, приложенный к проекту), или пользоваться напрямую файлом Python.

Преимущества программы:
1. Работоспособность.
2. Быстрая скорость работы программы.
3. Минимально необходимое заимствование сторонних библиотек и строчек кода.
4. Самые лучшие стандарты шифрования и хеширования на данный момент: AES-256 (Fernet) для шифрования, Argon2id для хеширования, PBKDF2 с 600,000 итераций для ключа, соль 32 байта.
5. Мастер-пароль (и все пароли) не хранится — только хеш.
6. Вся база JSON зашифрована целиком (при ошибке мастер-пароля база не запустится). Пароли хешируются с солью.
7. Полностью локальная автономная работа.
8. Весь проект содержится в одном файле формата "*.exe", что позволяет легко его запускать и распространять.
9. Простота в использовании программы.
10. Простота, стиль и читабельность кода.

Недостатки программы:
1. Минимальная функциональность.
2. Отсутствие графического интерфейса (GUI).
